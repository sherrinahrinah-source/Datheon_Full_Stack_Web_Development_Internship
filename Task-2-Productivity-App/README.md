# Task 2: Productivity App

## Overview
The Productivity App is a responsive task management application developed using HTML, CSS and JavaScript. It helps users organise their daily activities, manage tasks and monitor their productivity.

## Features

- **Add Tasks:** Create new tasks with a name, category and due date.
- **Edit Tasks:** Update existing task information.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **Complete Tasks:** Mark tasks as completed or undo completion.
- **Task Categories:** Organise tasks into Study, Work and Personal.
- **Search:** Find tasks quickly by name.
- **Task Filters:** View All, Active or Completed tasks.
- **Dashboard:** View total, active and completed task statistics.
- **Progress Tracking:** Monitor task completion using a progress bar.
- **Local Storage:** Automatically save tasks in the browser.
- **Responsive Design:** Supports desktop and mobile screens.
- **Dark Theme:** A modern dark interface for a comfortable experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run the Application

1. Download or clone the project repository.
2. Open the `Task-2-Productivity-App` folder.
3. Open `index.html` in a web browser.
4. Start adding and managing your tasks.

No server or database installation is required.

## Storage

The application uses the browser's Local Storage to save task information. Tasks remain available after refreshing the browser on the same browser and device, provided the browser data is not cleared.
