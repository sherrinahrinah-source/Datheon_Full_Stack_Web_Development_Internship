# NOIR FASHION – E-Commerce Storefront

## 1. Project Overview

NOIR FASHION is a modern, responsive fashion e-commerce storefront developed using HTML, CSS, and JavaScript.

The website allows customers to explore fashion products, browse product image galleries, search for items, filter products by category, and manage their shopping cart.

## 2. Features

- Modern dark-themed user interface.
- Responsive design for desktop, tablet, and mobile devices.
- Product catalogue with multiple images per product.
- Product image galleries with navigation arrows.
- Search functionality.
- Category filtering.
- Add products to cart.
- Increase and decrease product quantities.
- Remove products from the shopping cart.
- Automatic cart total calculation.
- Shopping cart data saved using Local Storage.
- Simulated checkout confirmation.

## 3. Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive layouts.
- JavaScript – Website functionality and interactivity.
- Browser Local Storage – Saving shopping cart information.

## 5. How to Run the Project

1. Download or clone the project repository.
2. Open the `Task-4-Ecommerce-Storefront` folder.
3. Open `index.html` in a web browser.
4. Browse products and test the available features.

An internet connection is required for externally hosted product images.

## 6. Testing

The following features were tested successfully:

- Product image galleries.
- Product search.
- Category filtering.
- Adding products to the cart.
- Updating product quantities.
- Removing products.
- Shopping cart persistence after refreshing the page.
- Checkout confirmation.

## 7. Important Note

The checkout feature is simulated for demonstration and learning purposes. The project does not currently process real payments.
